# Naming Convention

Name format of each file is as follows:
17_TelstraRNLI_NameOfDocument_SPXWX_YOURNAME

Notes:

- WX = Week, Change X with the week number (1 to 3)
e.g SP1W1 = Sprint 1 Week 1
